MOBILE ACCESS SETUP

1. GET YOUR IP ADDRESS
   Run in PowerShell:
   ipconfig

   Look for: IPv4 Address (e.g., 192.168.1.105)

2. UPDATE .env FILE
   Open: c:\Projects\school-saas\.env

   Change this line:
   VITE_API_BASE_URL="http://192.168.1.105:4000"

   (Replace 192.168.1.105 with your actual IP)

3. RESTART DEV SERVERS
   npm run -w apps/web dev
   npm run -w apps/api dev

4. OPEN ON MOBILE (same WiFi)
   http://192.168.1.105:5173

   (Replace IP with yours)

Done! Full app access from your phone.
