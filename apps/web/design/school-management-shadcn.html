Design System

This design follows the shadcn/ui aesthetic:

  • Neutral color palette with proper dark/light mode support
  • Clean typography and minimal visual hierarchy
  • Proper contrast ratios for accessibility
  • All 10 interactive .dc.html artboards + canvas.json in apps/web/design/
  • Theme toggle in header (light/dark mode) — add to main app
  • Multi-role support: Admin (desktop), Teacher (phone), Parent (phone)
  • Attendance confirmation is explicit (never auto-submit)
  • Consent is 4 independent toggles per DPDP requirements
