Design Fidelity
  • Component accuracy: Button, Card, Input, Label, Alert anatomy matches real shadcn source pixel-for-pixel
  • Monospace numerals: All numbers use system mono stack (SF Mono, Monaco) for deliberate "register" identity
  • Correct Tailwind slate: Neutrals from actual config (#f8fafc, #e2e8f0, #0f172a) — not invented hex
  • Teal accent restraint: Buttons (#0d9488), focus rings (#14b8a6), active tabs only — never washed or spread
  • Lucide-style icons: Clean, minimal SVG (2px stroke, round caps) matching installed lucide-react in your project
  • No sidebar: Matches real AppShell's top-bar-only architecture
  • Multi-role from day one: Admin (desktop), Teacher (phone, offline-first), Parent (phone, DPDP consent per-scope)
  • Attendance never auto-submits: Explicit "Confirm & submit" step on every marking (CLAUDE.md non-negotiable)
  • Consent is 4 independent toggles: GENERAL / AI / WHATSAPP / SMS — never a single checkbox (DPDP compliance)
